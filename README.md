# Number Guessing Game 🎯

A simple Python-based number guessing game for beginners.

## About the Project
The computer generates a random number between 1 and 100. The player must guess the number using hints provided by the program.

## Features
- Random number generation
- Higher and lower hints
- Multiple guessing attempts
- Attempt counter
- Winning message

## Technologies Used
- Python
- Random module
- While loop
- Conditional statements

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Run the following command:

```bash
python main.py
```

## Learning Outcomes
- Understanding Python loops
- Using conditional statements
- Working with random numbers
- Taking user input
- Using variables and counters
